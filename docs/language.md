## Язык программирования

Язык имеет C-подобный синтаксис (в духе C / Java / JavaScript). В нём один тип данных — машинное слово, поддерживаются математические выражения, функции (в том числе рекурсивные), массивы и строки.

### Синтаксис

Синтаксис описан в расширенной форме Бэкуса-Наура. Обозначения: `{ X }` — повторение `X` ноль или более раз, `[ X ]` — необязательный `X`, `|` — альтернатива. Терминалы записаны в кавычках, поэтому `"["` означает символ квадратной скобки, а не необязательную часть.

```ebnf
<program>        ::= { <top_item> }
<top_item>       ::= <const_decl> | <func_decl> | <statement>

<const_decl>     ::= "const" <ident> "=" <const_expr> ";"
<func_decl>      ::= "func" <ident> "(" [ <params> ] ")" <block>
<params>         ::= "auto" <ident> { "," "auto" <ident> }

<block>          ::= "{" { <statement> } "}"
<statement>      ::= <var_decl> ";"
                   | <if_stmt>
                   | <while_stmt>
                   | <for_stmt>
                   | <return_stmt>
                   | <block>
                   | <expression> ";"

<var_decl>       ::= "auto" <ident> [ "=" <expression> ]
                   | "auto" <ident> "[" <const_expr> "]"

<if_stmt>        ::= "if" "(" <expression> ")" <block>
                     [ "else" ( <block> | <if_stmt> ) ]
<while_stmt>     ::= "while" "(" <expression> ")" <block>
<for_stmt>       ::= "for" "(" [ <for_init> ] ";" [ <expression> ] ";"
                     [ <expression> ] ")" <block>
<for_init>       ::= <var_decl> | <expression>
<return_stmt>    ::= "return" [ <expression> ] ";"

<expression>     ::= <assignment>
<assignment>     ::= <lvalue> "=" <assignment> | <logic_or>
<logic_or>       ::= <logic_and> { "||" <logic_and> }
<logic_and>      ::= <bit_or> { "&&" <bit_or> }
<bit_or>         ::= <bit_and> { "|" <bit_and> }
<bit_and>        ::= <equality> { "&" <equality> }
<equality>       ::= <relational> { ( "==" | "!=" ) <relational> }
<relational>     ::= <additive> { ( "<" | "<=" | ">" | ">=" ) <additive> }
<additive>       ::= <multiplicative> { ( "+" | "-" ) <multiplicative> }
<multiplicative> ::= <unary> { ( "*" | "/" | "%" ) <unary> }
<unary>          ::= ( "-" | "!" | "~" ) <unary> | <postfix>
<postfix>        ::= <primary> { "[" <expression> "]" }
<primary>        ::= <number> | <char> | <string> | <ident> | <call>
                   | "(" <expression> ")"
<call>           ::= <ident> "(" [ <expression> { "," <expression> } ] ")"
<lvalue>         ::= <ident> | <postfix> "[" <expression> "]"
<const_expr>     ::= <expression>   (* вычислимое при трансляции, см. ниже *)

<ident>          ::= <letter> { <letter> | <digit> }
<letter>         ::= "a" .. "z" | "A" .. "Z" | "_"
<digit>          ::= "0" .. "9"
<number>         ::= <digit> { <digit> }
                   | "0x" <hex_digit> { <hex_digit> }
<hex_digit>      ::= <digit> | "a" .. "f" | "A" .. "F"
<char>           ::= "'" ( <symbol> | <escape> ) "'"
<string>         ::= '"' { <symbol> | <escape> } '"'
<escape>         ::= "\" ( "n" | "t" | "0" | "\" | "'" | '"' )
<symbol>         ::= любой печатный ASCII-символ, кроме "\" и кавычки-ограничителя
```

Комментарий начинается с `//` и продолжается до конца строки. Пробелы, табуляции и переводы строк между лексемами игнорируются.

Зарезервированные слова: `auto`, `const`, `func`, `if`, `else`, `while`, `for`, `return`, `in`, `out`.

Правило `<assignment>` нельзя разобрать, заглянув на один токен вперёд, поэтому парсер сначала разбирает `<logic_or>` и, если за ним стоит `=`, проверяет, что разобранное выражение является `<lvalue>`.

### Семантика

#### Структура и порядок выполнения программы

Программа — это последовательность объявлений констант, объявлений функций и операторов верхнего уровня. Операторы верхнего уровня выполняются сверху вниз в порядке записи. Объявление функции в этом порядке не участвует: тело функции выполняется только при её вызове. После последнего оператора верхнего уровня процессор останавливается. Отдельной функции `main` нет.

Функции объявляются только на верхнем уровне, вложенные функции не поддерживаются. Оператор `return` допустим только внутри тела функции.

#### Стратегия вычислений

Используется строгая (энергичная) стратегия вычислений: вызов по значению. Аргументы функции вычисляются слева направо до входа в функцию. Операнды бинарных операторов также вычисляются слева направо.

Исключение составляют логические операторы `&&` и `||`, которые вычисляются лениво. Если левый операнд `&&` равен нулю, правый не вычисляется и результат равен `0`. Если левый операнд `||` не равен нулю, правый не вычисляется и результат равен `1`. Это позволяет писать проверки вида `top > 0 && ops[top - 1] != '('`, где второе условие безопасно только при истинном первом.

Любое выражение возвращает значение. Присваивание — тоже выражение: оно возвращает присвоенное значение, поэтому допустимо `a = b = 0`. Вызов функции — выражение, поэтому каждая функция возвращает значение. Если функция завершилась без `return` или через `return;`, она возвращает `0`.

#### Типизация

В языке один тип — 32-битное знаковое целое в дополнительном коде (`auto`). Числа, символы, логические значения и адреса представлены одним и тем же машинным словом, и транслятор их не различает. Типизация, таким образом, отсутствует: ответственность за корректное использование значения лежит на программисте (как в языке B — предшественнике C).

Логическая истина — любое ненулевое значение, ложь — `0`. Операторы сравнения, `!`, `&&` и `||` возвращают `1` или `0`.

Арифметика выполняется по модулю 2³², переполнение не обнаруживается. Деление `/` округляет к нулю, остаток `%` имеет знак делимого (как в C и Go): `-7 / 2 == -3`, `-7 % 2 == -1`. Результат деления на ноль не определён.

#### Операторы

| Приоритет | Операторы            | Ассоциативность | Смысл                                   |

#### Литералы

Целочисленный литерал записывается в десятичной (`42`) или шестнадцатеричной (`0x2A`) системе и должен помещаться в 32 бита. Отрицательные числа получаются унарным минусом: `-1`.

Символьный литерал (`'h'`, `'\n'`, `'\0'`) — это просто число, равное ASCII-коду символа: `'h' == 104`. Поддерживаемые escape-последовательности: `\n`, `\t`, `\0`, `\\`, `\'`, `\"`.

Строковый литерал (`"hello"`) размещается транслятором в памяти данных как C-строка (`cstr`): каждый символ занимает одно машинное слово, в конце добавляется слово со значением `0`. Значение строкового литерала в выражении — адрес его первого символа. Строковые литералы предназначены только для чтения, результат их изменения не определён.

#### Константы

`const NAME = выражение;` объявляет именованную константу. Константы объявляются только на верхнем уровне. Выражение должно быть вычислимо при трансляции: оно может состоять из числовых и символьных литералов, ранее объявленных констант и операторов. Транслятор подставляет значение константы в место использования, память под неё не выделяется. Присваивать константе нельзя. Константы используются, в частности, как размеры массивов: `const BUF = 32; auto name[BUF];`.

#### Переменные и массивы

`auto x;` объявляет переменную, `auto x = выражение;` объявляет переменную с инициализацией. Инициализатор вычисляется в тот момент, когда выполнение доходит до объявления. Глобальная переменная без инициализатора равна `0`, значение локальной переменной без инициализатора не определено.

`auto buf[N];` объявляет массив из `N` машинных слов, где `N` — константное выражение. Имя массива в выражении означает адрес его первого элемента, поэтому массив передаётся в функцию как адрес, и функция может изменять его элементы (`read_line(name)`). Имени массива нельзя присвоить новое значение.

Индексация `e[i]` применима к любому выражению `e`: она обращается к машинному слову по адресу `e + i * 4` (адресация байтовая, слово — 4 байта). Благодаря этому параметр-адрес индексируется так же, как массив: `s[i]`. Выход за границы массива не проверяется.

#### Области видимости

Используется лексическая (статическая) блочная область видимости. Любое имя можно использовать только после его объявления в тексте программы, за одним исключением: функции видны во всей программе, что позволяет функции вызывать саму себя и функции, объявленные ниже.

Переменные, объявленные на верхнем уровне вне блоков, — глобальные: они видны от места объявления до конца программы, включая тела функций, объявленных ниже. Глобальные переменные и массивы размещаются в статической памяти.

Параметры функции и переменные, объявленные в её теле, — локальные: они видны от места объявления до конца содержащего блока и существуют только во время данного вызова функции. Каждый вызов получает собственную копию локальных переменных, поэтому рекурсия работает корректно. Переменная, объявленная в `<for_init>`, видна только внутри этого цикла.

Повторное объявление имени в том же блоке — ошибка трансляции. Локальная переменная может перекрывать глобальную с тем же именем.

#### Управляющие конструкции

`if (условие) { ... } else { ... }` выполняет первый блок, если условие не равно нулю, иначе второй (если он есть). Цепочка проверок записывается как `else if`.

`while (условие) { ... }` выполняет блок, пока условие не равно нулю; условие проверяется перед каждой итерацией.

`for (инициализация; условие; шаг) { ... }` эквивалентен записи:

```c
{
    инициализация;
    while (условие) {
        ...
        шаг;
    }
}
```

Пропущенное условие считается истинным.

`return выражение;` вычисляет выражение, завершает функцию и возвращает результат в место вызова.

#### Ввод-вывод

Ввод-вывод выполняется встроенными функциями, работающими с потоком символов:

- `in()` читает из потока ввода один символ и возвращает его код. Если данные во вводе закончились, моделирование останавливается.
- `out(e)` записывает в поток вывода один символ с кодом, равным младшему байту `e`, и возвращает `e`.

Встроенные функции транслируются в обычные инструкции чтения и записи по адресам портов, отображённым в память (вариант `mem`), см. раздел «Организация памяти». Все остальные операции со строками, такие как печать строки или чтение строки, реализуются функциями на самом языке.

### Пример программы

```c
const BUF = 32;
auto name[BUF];

// печатает C-строку посимвольно
func print_str(auto s) {
    auto i = 0;
    while (s[i] != '\0') {
        out(s[i]);
        i = i + 1;
    }
}

// читает строку до '\n' в buf, возвращает длину или -1 при переполнении
func read_line(auto buf) {
    auto i = 0;
    auto c = in();
    while (c != '\n') {
        if (i >= BUF - 1) {
            return -1;
        }
        buf[i] = c;
        i = i + 1;
        c = in();
    }
    buf[i] = '\0';
    return i;
}

print_str("What is your name?\n");
if (read_line(name) == -1) {
    print_str("name too long\n");
} else {
    print_str("Hello, ");
    print_str(name);
    out('\n');
}
```

Выполнение «на листе бумаги» при вводе `Alice\n`:

1. Объявления `BUF`, `name`, `print_str`, `read_line` ничего не выполняют: константа `BUF` подставляется как `32`, массив `name` из 32 слов размещён в статической памяти и заполнен нулями.
2. Первый оператор верхнего уровня вызывает `print_str` с адресом строки `"What is your name?\n"`. Цикл выводит символы, пока не встретит завершающий `0`.
3. `read_line(name)` читает `A`, `l`, `i`, `c`, `e` в `name[0..4]`, затем читает `'\n'`, записывает `0` в `name[5]` и возвращает `5`.
4. `5 == -1` даёт `0`, поэтому выполняется ветка `else`: выводятся `Hello, `, затем содержимое `name`, затем перевод строки.
5. Операторы верхнего уровня закончились, процессор останавливается. Вывод: `What is your name?\nHello, Alice\n`.
